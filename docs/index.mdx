Bun OS ships the Aphrody Bun runtime as the system runtime of an Arch Linux distribution. One
repository builds the image, the COSMIC desktop, the Gamescope gaming session and the
applications, with pacman/libalpm as the package manager.

## Compositions

| Composition | Session          | Purpose                                     |
| ----------- | ---------------- | ------------------------------------------- |
| `server`    | none             | Headless host: Bun services, nginx, systemd |
| `desktop`   | `cosmic-session` | COSMIC desktop with the Material 3 shell    |
| `gaming`    | `gamescope`      | Steam/Proton gaming session                 |

## Profiles and targets

- `full`: wgpu renderer and every optional engine.
- `perf`: tiny-skia renderer and demand-loaded engines.
- Targets: `linux-x64`, `linux-arm64`, `windows-x64`, `macos-arm64`, `wasm`.

`distribution.json` declares profiles, targets and compositions. `sources.lock.json` pins every source revision.
