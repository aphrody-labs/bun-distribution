# Third-party notice status

`THIRD_PARTY_LICENSES.md` is a generated Rust dependency inventory from the locked application graph. It is a review aid, not a substitute for shipping each upstream license text where required.

The combined Bun/TypeScript lockfile and vendored trees require a separate resolver before claiming exhaustive legal coverage. The release gate must fail closed until every redistributed artifact has an identified license, upstream URL and required notice text.
