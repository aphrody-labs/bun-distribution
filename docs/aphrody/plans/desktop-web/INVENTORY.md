# Single CEF runtime: inventory of wry, tao, GTK3 and WebKitGTK references

Date: 2026-10-05. Owner order (verbatim): "on migre tout agressivement en mode yolo vers
tauri-runtime-cef (CEF + tauri-winit + GTK4). on ne supporte qu'un seul choix pour économiser des perfs
et du temps". This reverses decision 20 (wry/tao kept). The design, the decisions and the evidence are in
[PLAN.md](PLAN.md); this file is the exhaustive list of what references the old runtime and what happens to it.

Every row carries its decision, marked `tranché`: **remove** (deleted), **migrate** (rewritten for CEF) or
**keep** (left as is, with the reason). Nothing is left undecided.

## Method

- Pattern (case-insensitive): `wry`, `tauri-runtime-wry`, `aphrody-wry`, `tao`, `aphrody-tao`, `tao-macros`,
  `tauri-driver`, `webkit2gtk`, `webkitgtk`, `libwebkit2gtk`, `gtk3`, `libgtk-3`, `libappindicator`,
  `ayatana`, `webview2`, `WKWebView`, `msedgedriver`, `WebKitWebDriver`, `system webview`.
  `rg -i` over the working tree, `.gitignore` honoured.
- Left out on purpose: `Cargo.lock` (diffed separately), `CHANGELOG.md` files (upstream release notes),
  `docs/plans/fusion` (owned by the V8/JSC arbiter; it already records decision 21 and receives a message),
  generated catalogues (`docs/ecosystem`, `docs/migration` (not in repo) (former migration record directory; retained as a historical reference)), and the five crates being deleted.
- JavaScriptCore/WebKit as Bun's engine (the V8 versus JSC work) is a different subject and is not matched.
- Result: 305 files with 1544 matches outside the deletion set, plus the deletion set itself: 243 files,
  69,209 lines, 2.5 MB (`aphrody-wry` 19,577 lines, `aphrody-tao` 38,826, `aphrody-tao-macros` 702,
  `aphrody-tauri-runtime-wry` 9,489, `aphrody-tauri-driver` 615).
- Cargo graph (linux target, `cargo metadata --offline`, before the change): 236 workspace members, 2,052
  resolved packages, 2,719 lock packages, 42 members reaching `gdk-sys`/`gtk-sys`/`gtk4-sys`/`webkit2gtk-sys`
  through normal or build edges (56 with dev edges), 56 members reaching the GTK3 `-sys` crates.

| Removed                                                                        | Why                                                                                                                  |

| plugins barcode-scanner, biometric, nfc, haptics, geolocation                  | mobile only; Aphrody ships no mobile target                                                                          |
