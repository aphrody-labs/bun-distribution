# Contributors

## 1. Recognition

Every contributor to `aphrody-code/aphrody` is listed here. Format: GitHub
handle plus a one-line role or first significant contribution.

## 2. Maintainers

- `@aphrody-code` — repo owner, primary maintainer.

## 3. Contributors

_When the first external contributor lands, add their handle here,
alphabetically. Initial state: empty (autonomous-loop bootstrap, no external
contributors yet)._

## 4. How to add yourself

- Open a PR that adds your line under §3 Contributors after your first merged
  PR.
- Format: `- @handle — <role or first contribution one-liner>`.
- See [`CONTRIBUTING.md`](./CONTRIBUTING.md) for the full PR process.

## 5. Security researchers

Security researchers who responsibly disclose are credited per the process in
[`SECURITY.md`](../../research/ai/SECURITY.md) — see its acknowledgement policy for security work.
