# ── Mode Aphrody ───────────────────────────────────────────────────────────────────────────
# L'aura « Mode Aphrody » / « Lord Aphrody Mode » (アフロディモード) a trois paliers, déclarés
# dans skill/aura_skill_config_1.04.09.00.cfg.bin → AURA_CMD_INFO. Leur nom interne
# `mode_change_c11150120` porte le code d'Archon Aphrodite : c'est son changement de mode.
#
#   0x03D98821  mode_change_c11150120          (base,   coûts 75/90)
#   0x0438CBD2  mode_change_c11150120_exst     (        coûts 90/90)
#   0x3220427E  mode_change_c11150120_legend   (        coûts 90/90)
#
# Promouvoir le palier de base en palier légendaire partout où il est chargé. Décommenter pour
# l'activer — la ligne touche la table d'auras en mémoire, pas un seul personnage.
# u32 0x03D98821 -> 0x3220427E
