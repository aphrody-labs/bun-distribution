# Code of conduct

This project is small and technical. The rules are correspondingly short.

## Expected

- **Argue with the measurement, not the person.** Disagreement here is settled by a command
  someone can re-run. "That number is wrong, here is the output I get" is the whole ritual.
- **Say what you did not verify.** An unverified claim declared as unverified costs nothing. The
  same claim presented as measured costs the next person a day.
- **Assume the other reader has the context you lack.** Several people and several agents work
  this repository in parallel; a change that looks pointless usually has a reason recorded in
  `PLAN.md`, `AGENTS.md` or a commit message.

## Not accepted

- Personal attacks, harassment, or demeaning remarks about anyone — including about their level
  of experience with reverse engineering, Rust, or this codebase.
- Sexualised language or imagery, and unwelcome attention of any kind.
- Publishing someone's private information without their explicit permission.
- Sustained disruption: reopening a settled decision without new evidence, or re-submitting a
  refused contribution unchanged.
- Posting copyrighted game content — assets, decrypted tables, dumps of game text. This one is
  also a legal boundary, not only a social one. See [`NOTICE`](NOTICE).

## Scope

Issues, pull requests, commit messages, code review, and any space where you are identifiably
acting on behalf of this project.

## Reporting

Write to `yohanpierre15@gmail.com`. Reports are read by the maintainer and not shared further
without the reporter's agreement. If your report concerns the maintainer, say so — there is no
pretence here that an internal process is independent, and you are entitled to take it to GitHub
Support instead.

Expect an acknowledgement within 72 working hours. Responses range from a private request to
change behaviour, to removing a comment, to blocking an account, depending on severity and on
whether it has happened before.

## Security reports go elsewhere

A vulnerability is not a conduct issue: follow [`SECURITY.md`](../../research/nie/SECURITY.md). Do not open a public
issue for an uncorrected flaw.
