# Archived integration journal

This journal records a 2026 desktop integration pass. Its implementation details and
verification results describe that historical revision only; several listed routes,
commands and adapters have since been removed or changed.

Use the [GUI contract](./GUI.md) for the current webview boundary, the
[desktop integration guide](./DESKTOP-INTEGRATION.md) for packaging, and current source
for implementation status. The webview is limited to Chat, Files, Models and Settings;
browser/crawler administration and shell/PTY/terminal surfaces are excluded.
