## Default Permission

Every Aphrody Drive command: daemon bridge, explorer windows, files, file opening, drag and drop, keybinds, menu and daemon service control.

#### This default permission set includes the following:

- `allow-open-drive`
- `allow-app-ready`
- `allow-get-daemon-socket`
- `allow-get-server-url`
- `allow-get-current-library-id`
- `allow-set-current-library-id`
- `allow-get-selected-file-ids`
- `allow-set-selected-file-ids`
- `allow-daemon-request`
- `allow-subscribe-to-events`
- `allow-unsubscribe-from-events`
- `allow-get-daemon-status`
- `allow-start-daemon-process`
- `allow-stop-daemon-process`
- `allow-check-daemon-installed`
- `allow-install-daemon-service`
- `allow-uninstall-daemon-service`
- `allow-open-macos-settings`
- `allow-begin-drag`
- `allow-end-drag`
- `allow-get-drag-session`
- `allow-force-clear-drag-state`
- `allow-reveal-file`
- `allow-share-files`
- `allow-get-sidecar-path`
- `allow-get-apps-for-paths`
- `allow-open-path-default`
- `allow-open-path-with-app`
- `allow-open-paths-with-app`
- `allow-register-keybind`
- `allow-unregister-keybind`
- `allow-get-registered-keybinds`
