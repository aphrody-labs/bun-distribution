# Archived agent app proposal

This 2026 concept included terminal/PTy, embedded browser/crawler and host
administration panes. These proposals are superseded and are not part of Aphrody's
consumer UI. Do not implement routes or controls from the old wireframes.

The current product surface is Chat, Files, Models and Settings. Follow the
[GUI contract](./GUI.md), [UI rules](./UI-RULES.md) and
[native desktop policy](./NATIVE-DESKTOP.md). Optional shell or browser products
belong in separately packaged, mature Rust applications.
