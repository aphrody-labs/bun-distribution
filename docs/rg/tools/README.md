# Archive — outils Azalée autonomes

Les anciens outils d'avatar, galerie, 3D, comparaison et exploration ne sont
plus des surfaces de l'application web Azalée. Ils ont été migrés vers le
dépôt `niers` ou retirés.

Ne pas recréer leurs routes, menus ou builds dans `apps/website`. Le contrat de
la surface web actuelle est [Azalée dans Website](../azalee.md).
