# Shenron local bridge

Shenron owns its local profile and editorial data. The former profile generator command (`bun scripts/dev/local-env.ts env`) is not present at that path in the current monorepo; see `shenron:docs/operations/DEV-LOCAL.md` ([aphrody-labs/shenron](https://github.com/aphrody-labs/shenron)) for the archival status. The variable inventory is in `shenron:docs/operations/ENV.md`. Aphrody reads ignored app `.env.local` files when explicit process environment variables are absent. It never copies tokens into this repository.

`aphrody shenron doctor --json` probes the local site, bot, selected RAG engine, Aphrody AI HTTP service, and the validated seven-file `dbfr` Agent Home. The exact value `RAG_BACKEND=aphrody` selects authenticated `/api/v1/shenron/*` RAG routes; every other value selects the bot's `/api/public/rag/search` and `/api/ia/status` routes, matching `@shenron/pipeline/ai/config`. `rag eval` calls the bot's authenticated `POST /api/training/eval`; this measures retrieval on Shenron's gold set and does not train model weights. `persona ask` loads the current Agent Home revision, retrieves from the selected RAG engine, and calls Aphrody AI chat with those sources.

The current local defaults are `http://shenron.localhost:18080` for the site and `http://127.0.0.1:15006` for the bot. `SHENRON_SITE_URL` and `SHENRON_API_URL` override them. The AI origin and bearer token use `APHRODY_AI_HTTP_URL` and `APHRODY_AI_HTTP_TOKEN`, with the legacy `APHRODY_SHENRON_*` aliases supported. `SHENRON_ADMIN_TOKEN` (or `API_ADMIN_TOKEN`) authenticates bot admin evaluation. No PostgreSQL or Redis credentials are used by the CLI: Shenron and the Aphrody AI backend own their databases.

The Infra catalog currently marks the VPS AI HTTP and E5 services as retired. A URL in a local environment file does not mean its tunnel or target is running. Use `aphrody shenron doctor --json` for the CLI's live probes; the old documented `bun scripts/dev/local-env.ts status` command is unavailable at that path. When the bot or selected RAG engine is down, search and evaluation fail without reading its private database directly.

`aphrody agent --profile dbfr` resolves an existing `~/.aphrody/workspaces/dbfr` as its live Agent Home. Its sessions and RAG state live under `~/.aphrody/profiles/dbfr`; the seven Markdown files remain in the Agent Home. Edits to them are loaded at the next Aphrody agent turn. Shenron's bot and site currently use their own persona prompts and Redis conversation memory, so editing `SOUL.md` changes the Aphrody agent and `aphrody shenron persona ask`, but does not yet change Shenron's deployed bot persona.

`aphrody shenron train` produces candidate artifacts only. It requires explicit training inputs and uses the Aphrody Python training project; no candidate is promoted into Shenron's E5 index without measured compatibility and a shadow-index evaluation. Wiki changes by agents follow Shenron's scoped API and moderation workflow.
