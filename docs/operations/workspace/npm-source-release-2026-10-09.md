# Aphrody npm source release, 2026-10-09

The owner authorized public npm publication of all independently packaged first-party producers. The Git repositories retain their existing visibility. Protected authentication, cookies, sessions, databases, models and host configuration are excluded.

## Scope and artifacts

All 73 first-party producer archives passed package identity, declared export, dependency-specification and protected-path checks. Registry archive content comparisons identified 53 changed source packages; seven additional releases close their workspace dependency graph. Sixty producers received current-source releases; thirteen unchanged producers retain their published versions. The public M3 example was subsequently aligned to the 3.3.9 lockstep policy, superseding 0.1.1. The private root aphrody manifest is an unversioned workspace catalog with no independent entry point and is not an npm producer.
