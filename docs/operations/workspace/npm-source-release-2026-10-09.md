## Packaging corrections

Paths bundles the canonical shared paths implementation and declarations into its own archive. Yolo Core packages only the canonical layout policy, while producer-host configuration remains isolated. CLI forge imports its declared Workspace owner. Google imports the declared Core edge-proxy owner. App UI excludes development-only showcase scripts. Product includes its required public creator glossaries. Workspace exposes its packaged operations entry point and includes the glob-aware IECODE doctor. M3 Config resolves its declared polyfill without a checkout-relative fallback. Canvas reports its actual released version. Windows tests normalize archive line endings and wait for the owned A2A server process before fixture cleanup.

## Qualification

The M3 owner pipeline completed 23 fresh TypeScript checks and 12 JavaScript/declaration builds; eleven packages have no build configuration. Doc AI and Discord builds and TypeScript checks passed. Core, CLI, Canvas, Workspace and scoped OS/Web package TypeScript gates passed. Relevant Windows A2A tests passed all 18 real Rust-server JSON-RPC and HTTP/SSE checks. The isolated Core policy test and forge module import passed. Google tests passed 26 checks and skipped 18 requiring protected stores. WASM/RAG/Timeline tests passed 34 checks and skipped one native CLI parity check. Shell Web passed ten WASM/transport checks; three browser/PTY/OPFS checks require their qualified runtime. Runtime SDK passed 19 core checks and skipped 39 native/provider/GPU checks requiring artifacts.

Broader suites retain explicit limits: M3 recorded 1892 passing, 42 skipped and 39 failing tests; Product recorded 297 passing, 16 skipped and five failing Windows SSH/jobs tests; the example guestbook recorded six passing and one response-parser failure; combined Doc AI/Discord/WinClean checks recorded 140 passing and one missing-supervisor failure. Wider Core/forge checks include Windows path assumptions and a repository-wide retired-path guard. Native browser checks require the absent Aphrody FFI runtime DLL. These results do not establish complete runtime, GPU, deployment or application qualification.

Initial canonical registry installation of the nine IECODE dependencies, frozen reinstall, imports and paths behavior passed before the broad source release. Earlier update 0.1.3, Bun 3.3.9 and X 1.3.1 had stale lock-derived dependency pins and are superseded by the audited closure. Bun lock regeneration precedes packing. npm metadata and tarballs may propagate at different times; successful upload alone is not consumer availability.
