# Integration guide retired

This upstream integration guide described the old `@spacedrive/*` package
workspaces and link scripts, which are no longer present here. Aphrody consumers
use the maintained `@aphrody/m3-*` packages directly. See the repository root
README and `docs/architecture/ui/design/SPACEUI-M3-FUSION.md` for the current package map.
