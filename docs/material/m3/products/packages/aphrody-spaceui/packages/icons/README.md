# Archived SpaceUI icon source

This is a provenance reference, not an installable or buildable package. Production imports use
[`@aphrody/assets`](../../../assets), which retains the MIT notice and exact canonical copies.

On 2026-09-28, 619 byte-identical files (11,121,998 bytes) were retired from this reference
tree. `RETIRED-DUPLICATES.json` records every source path, SHA-256,
size, and canonical asset path; `bun scripts/archive-spaceui-icons.ts --check` verifies them.
Four divergent source and metadata files plus two upstream-only files remain for review. The stale package manifest and TypeScript build config were retired with the runnable package entrypoints. The parent SpaceUI
source snapshot and MIT terms remain in `LICENSE` and [`UPSTREAM.txt`](../../../../../reference/packages/aphrody-spaceui/UPSTREAM.txt).
