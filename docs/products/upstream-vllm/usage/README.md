# Using vLLM

First, vLLM must be [installed](../../../guides/upstream-vllm/getting_started/installation/README.md) for your chosen device in either a Python or Docker environment.

Then, vLLM supports the following usage patterns:

- [Inference and Serving](../../../reference/upstream-vllm/serving/offline_inference.md): Run a single instance of a model.
- [Deployment](../../../operations/upstream-vllm/deployment/docker.md): Scale up model instances for production.
- [Training](../../../reference/upstream-vllm/training/rlhf.md): Train or fine-tune a model.
