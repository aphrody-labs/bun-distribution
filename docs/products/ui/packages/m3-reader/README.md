# @aphrody/m3-reader

Material 3 React readers for paged and vertical manga and illustrated books. This package owns the reader UI, paging, virtual scrolling, zoom, fullscreen, thumbnails, keyboard controls, and lightbox focus. It does not own an asset server, editorial API, persistence, or OCR policy.

Import `@aphrody/m3-reader/styles.css` once in the host stylesheet. The host must load Tailwind 4 and scan the package's `dist` directory with `@source`, as with other Aphrody M3 component packages. CSS colors use Material 3 `--md-sys-color-*` roles, with readable fallbacks. The reader can also be themed through `--reader-surface`, `--reader-on-surface`, `--reader-accent`, `--reader-on-accent`, and `--reader-outline`.

For Shenron's Dragon Ball appearance, also import `@aphrody/m3-reader/dragon-ball.css` and wrap readers in `class="m3-reader--dragon-ball"`. All 12 editable `--dbz-*` palette values and the corner radius remain live, including `/admin/design` overrides. The reader theme also carries the measured slanted badge, ink border, tactile controls, and orange scrollbar conventions. The fallback colors follow Shenron's documented cover measurements in `docs/couverture-analyse-visuelle.md`; this package does not add new artwork. Shenron still owns the global site theme editor and the measured full palette used outside readers.

`MangaReader` accepts page URLs, direction, adjacent chapter links, an asset resolver, an optional mirror resolver, and callbacks for page addressing. `DatabookReader` accepts numbered pages, an abortable transcription loader, a transcription renderer, image optimization callbacks, and a preload count. `CollectionReader` owns edition and chapter controls; the host supplies its edition grouping and chapter renderer. The host supplies domain-specific loading and rendering.

Shenron uses the `/source` export through thin adapters in its manga and databook components, so a fresh local clone does not require a prebuilt `dist`. Next transpiles the package and Tailwind scans its `src`. The root export points to compiled `dist` for regular package consumers. Shenron remains responsible for asset routing, API links, reading history, on-demand transcription retrieval, OCR warnings, correction links, and Markdown rendering. The local `file:` dependency requires both repositories in the same parent directory until this package is published and Shenron switches to a registry version.
