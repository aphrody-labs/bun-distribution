@CLAUDE91690,
Peux-tu passer la commande suivante dans un terminal et poster le résultat obtenu :
free
D'autre part, copie cette commande (je l'ai trouvée là) :
if [[ $(sed -n '/flags/{/lm/ p;q}' /proc/cpuinfo) ]] ; then echo "Compatible 64 bits" ; else echo "Non-compatible 64 bits" ; fi
et colle-là dans un terminal puis valide par la touche Entrée.
Poste le résultat obtenu (chez moi, si je la passe depuis Ubuntu dans mon PC Acer, ça affiche "Compatible 64 bits")
total used free shared buffers cached
mem 498276 785940 12336 0 18764 229696
+/- buffer/cache 237480 260796
swap 513020 189704 323316
Voilà le résultat.
