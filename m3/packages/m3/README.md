# @aphrody/m3

The Material Design 3 framework for Bun: one plugin, a dev server, a builder and the `m3` CLI.

- `m3Plugin` (`@aphrody/m3/plugin`, also the bunfig `[serve.static]` plugin): Tailwind v4, Sass
  through Rust, the virtual modules `m3:theme.css`, `m3:tokens.css`, `m3:tailwind.css`,
  `m3:spaceui.css`, `m3:scheme.css`, `m3:fonts.css`, `m3:symbols-<outlined|rounded|sharp>.css`, and
  `?url` imports.
- `serveM3` (`/server`): `Bun.serve` with HMR and proxy. `buildM3` (`/build`): `Bun.build`, with the
  Tauri webview layout (`index.html`, `app.js`, `app.css`, `fonts/`). `defineM3Config` (`/config`).
- `M3App` for React (`/react`) and Lit (`/lit`); `/i18n`; ambient module types in `/client`.

```sh
m3 new my-app && cd my-app && bun install
m3 dev                      # m3.config.ts in the working directory
m3 build --tauri ../ui-dist
m3 tokens --sheet scheme --seed '#6750a4' --dark
```

For an App Router project (`app/`), `m3 compile [--target bun-linux-x64-musl] [--outfile]` builds and links one
executable (`bin/<name>`, `PORT`/`HOSTNAME` from the environment), and `m3 docker [--outdir] [--base] [--tag]` writes
a Docker context (`.m3/docker`: `server.js`, `dist/`, a Dockerfile on `ghcr.io/aphrody-labs/alpine:3.24-runtime`)
and runs `docker build` when `--tag` is given.

Inside the Aphrody checkout the same commands run as `yolo m3 <command>`; `yolo m3 --help` also lists the
m3 package tools (`yolo m3 next|bun|os-themes|next-migrate|svg-to-ico|web-to-tauri|scaffold`).

Sheets are generated by `m3Css` of `@aphrody/bun` (the Rust token exporter, loaded lazily); see
[docs/guides/NATIVE.md](../../docs/guides/NATIVE.md) for the native library. Fonts resolve from an
aphrody checkout (`crates/ui/bun/icons/material-symbols`, `crates/ui/m3-tokens/fonts`) or from
`packages/m3-fonts/fonts/upstream` synced by `bun scripts/fonts-sync.ts` (`fontLayout`, `fontPaths`).

Scripts: `build` (`scripts/build.ts`), `typecheck`, `test` (fonts sync, then `bun test`; the
`m3Css` FFI suite skips with its reason when the native library is absent).
