# @aphrody/scaffold

The single scaffolder of the UI stack: Tauri 3 shell, `web`, `app` and `example` templates and a
writer that never overwrites. Guide: [`docs/guides/ui/SCAFFOLD.md`](../../docs/guides/SCAFFOLD.md).

```sh
bun run ui:scaffold list
bun run ui:scaffold example ../aphrody-example
```
