# Retired SpaceUI forms workspace

The local `@spacedrive/forms` compatibility package was removed: its only source
was a re-export facade and the archive is excluded from the Bun workspace. Use
[`@aphrody/m3-forms`](../../../../../../packages/m3-forms) for maintained M3 form components.

Upstream release history is retained in `CHANGELOG.md`; source lineage and the
MIT license are recorded in the archive-level `UPSTREAM.txt` and `LICENSE`.
