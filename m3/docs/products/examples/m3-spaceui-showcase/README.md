# m3-spaceui-showcase

Every SpaceUI component rebuilt on Material Design 3 (`@aphrody/m3-primitives`, `m3-forms`,
`m3-ai`, `m3-explorer`, `assets`), switchable across the seven SpaceUI themes rendered as M3
dynamic schemes (`@aphrody/m3-theme/spaceui.css`). Port of `docs/products/ui/packages/aphrody-spaceui/examples/showcase`,
on Bun instead of Vite.

```sh
bun run dev      # m3 dev: Bun.serve + HMR, http://localhost:19850
bun run build    # m3 build: static build into dist/
bun run typecheck
```

The app is declared in `m3.config.ts`; `bunfig.toml` loads `@aphrody/m3/plugin` (Tailwind v4 and
the `m3:*` modules) for the dev server. Material Symbols and Google Sans Flex come from
`m3:symbols.css` and `m3:fonts.css`. `tsconfig.json` maps the `@aphrody/m3-*` packages to their
sources for the typechecker.
