# Reference screens

Links to official captures of the reference system UIs, mapped to the screen IDs in
`../recon.md`. The images are copyrighted (editorial/press use, Wikipedia fair use or publisher
rights) and are **not downloaded or versioned**: open them in a browser for layout comparison
only. They never go into Bun OS. Downloading any of them needs the owner's explicit approval.

Index: [`assets/reference/console-ui/manifest.json`](../../assets/reference/console-ui/manifest.json)
(sizes, licences and survey date 2026-10-17). License codes: ED editorial/press, FU Wikipedia
fair use, NL no licence stated, LIB free licence.
