# Owner objective

Build an OS distribution with Bun as its application kernel, the COSMIC
desktop from cosmic-epoch, a cross-platform libcosmic fork, and an edition
of the owner reference “9937-389B”. Deliver Docker and WASM targets.
Create the requested OS integration branches while retaining the canonical
Bun runtime owner. Provide complete and performance editions with complete
locked Material and Bun fork sources.

Material owns the native Material 3 framework, its existing token and dynamic
color engine, libm3, the COSMIC adapter and the scalar WASM binding. Reuse
those owners for application/interface families. Preserve native control,
accessibility, focus, keyboard, layout and design-token semantics across
qualified web, native and COSMIC targets.

Integrate the existing Linux, WSL, WSLg and WSL kernel forks. Maintain the
official APT fork, Debian package/source support and apt.exe as a Windows
deliverable. Convert Ubuntu, COSMIC, Debian, MSYS2, MinGW and Cygwin packages
and sources into WinGet and Bun workflows, preserving dependencies, ABI,
provenance and licenses. Qualify the native libapt installation engine and
package transactions separately from the Bun conversion frontend.

Use the VPS for authenticated Ubuntu source retrieval and an OS build factory
following Ubuntu contributor guidance. Keep factory outputs on the qualified
build filesystem and preserve active work and protected data. The authorized
50 GB reclamation covers inventoried, disposable VPS classes.

Use glibc for Linux desktop editions and explicit native ABIs elsewhere.
Follow Linux, Debian, COSMIC and Bun conventions. Product documentation belongs
in README/docs, work status in PLAN.md, and session decisions in MEMORY.md.

Prepare unified deployment for the real applications in the owner's selected
workspace. Maintain their Cloudflare subdomains through Cloudflare MCP.
Compile complete standalone executables with the qualified Bun/runtime/native
owners. Store shared R2 assets by content identity, with app references to one
object per digest. Provision the chosen Rust deployment control plane and
self-hosted forge/workflow runners only after their host, authentication,
persistent storage and native job gates are satisfied.

Host hardware kernels remain platform-specific. A scalar libm3 WASM artifact
does not complete Bun/JSC/desktop WASM. Routing to the existing public Worker
does not complete app deployment. The full objective requires real source
exports, desktop/rootfs/images, runtime source-pin agreement, native libapt,
application execution and performance evidence. The owner reference
9937-389B must be identified before its edition can be qualified.
