Material 3 color tokens

Aphrody's Material 3 framework separates semantic color roles from component styling. m3/packages/m3-tokens/src/dynamic-color.ts exposes seed-based scheme utilities including schemeFromSeed, cssFromSeed and applyDynamicColor.

HCT and semantic roles

HCT represents hue, chroma and tone. A seed and scheme configuration resolve roles such as primary, surface and their associated foreground colors. Components consume roles rather than assuming that one hexadecimal value fits every theme.

Contrast and accessibility

Theme configuration is not a blanket accessibility guarantee. Check contrast, keyboard navigation, focus indicators and readable text in the rendered light and dark interfaces, including custom component states.
