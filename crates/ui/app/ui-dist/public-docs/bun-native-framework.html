Bun and the Aphrody UI

The Bun fork owns runtime changes, built-in modules and Bun build tooling. Aphrody owns application behavior and the canonical UI in m3/packages/app-ui.

Shared interface

The app-ui package contains product documentation, project templates and application routes. Its build script produces the frontend consumed by the native site and desktop shell. The former apps/web checkout is retired and is not the current build entry point.

Framework adapters

m3/packages/m3-next contains the Next.js adapter. Tailwind and Material 3 packages have their own manifests and build contracts. Consult the selected package and Bun fork documentation before choosing an API; package presence does not prove production activation or comparative performance.
