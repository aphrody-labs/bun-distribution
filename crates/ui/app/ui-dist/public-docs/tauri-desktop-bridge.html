Aphrody desktop and the shared UI

The desktop shell lives in crates/ui/app. Its manifest selects tauri-runtime-cef; its Tauri configuration sets frontendDist to ui-dist and declares the main window. The canonical frontend lives in m3/packages/app-ui.

Shared RPC

m3/packages/app-ui/src/tauri-bridge.ts routes aphrodyRpc through the aphrody_rpc desktop command inside Tauri and through same-origin POST /rpc in the browser. The app-server requires an initialization handshake. Studio also contains explicitly registered native commands; a web route does not automatically gain desktop privileges.

Deployment boundary

A configured frontend and a compiled shell are separate from an installed application running on a physical desktop. Check the installed artifact and its supported target before claiming native activation. The former apps/web ping bridge is not the current architecture.
