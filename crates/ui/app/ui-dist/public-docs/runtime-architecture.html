Aphrody OS runtime and native SDK

Aphrody OS brings a browser interface, a desktop shell and a cross-platform CLI around shared capability owners. The runtime comes from the private aphrody-labs/bun fork. Product workflows and the canonical interface remain in the Aphrody monorepo.

Bun runtime

Bun provides the JavaScriptCore runtime, Web APIs, bundler, package manager and test runner. Fork API documentation lives in the fork's docs/ tree. Aphrody records its selected documentation revision in docs/reference/upstream-bun/SOURCE.json; it does not maintain a second Bun documentation tree.

Native SDK

packages/engine/runtime declares @aphrody/runtime-sdk. Its FFI loader uses dlopen from bun:ffi. The native library boundary is aphrody_ffi in crates/interop/ffi, and include/aphrody.h retains the aphrody_* and yolo_* compatibility identities. The ABI contract requires version checks, opaque handles and library-owned buffer release.

Qualification

Source declarations do not prove that every native module is installed or active on every platform. Check the selected artifact, ABI and target before enabling a native capability.
