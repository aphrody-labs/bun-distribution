Agent context and isolated memory

AGENTS.md defines repository conventions and capability ownership. PLAN.md records the active architecture and queue, while MEMORY.md records dated evidence and limits. These files guide coding agents; they do not change model training.

Public context

The live https://aphrody.com/llms.txt endpoint returned an Aphrody overview during the 2026-10-09 audit. Treat it as a public context document rather than a guarantee of search indexing, ranking or deployment completeness.

Native memory

aphrody home and aphrody graph provide the native home and graph surfaces. The aphrody, dbfr and ie profiles remain isolated. Provider authentication, cookies and raw provider histories stay in their protected stores; no provider-memory synchronization is implied.
